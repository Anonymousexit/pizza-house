# Pizza House

A photographic restaurant homepage inspired by the supplied WarPigs reference. Uses all five supplied images, compressed to WebP.

Run `npm start` and open http://127.0.0.1:4173. No dependency installation or build is required. The deployable site is in `dist/`.

Features: responsive layouts, fixed navigation, scroll parallax and reveals, reduced-motion support, accessible mobile navigation, and a keyboard-accessible menu dialog with category tabs.

The brand copy and sample menu are creative concept content. Actual menu, prices, address, opening hours and reservation/ordering integrations have not been supplied. The homepage makes these pending details clear and does not send bookings or process payments.

Motion update: continuous spring-smoothed hero wordmark docking, custom pointer with hover and press feedback (fine pointers only), persistent light/dark appearance, and an animated tasting-card dialog with category tabs, numbered item selectors, keyboard navigation and touch swipes. Scrollbars are hidden while scrolling remains available on short screens. Reduced-motion preferences disable spring and entrance animations.
